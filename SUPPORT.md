# Support

Read the documentation and create a small synthetic example before requesting
help.

- Documentation: <https://el-cordero.github.io/potentiomap/>
- Issues: <https://github.com/el-cordero/potentiomap/issues>
- CRAN: <https://CRAN.R-project.org/package=potentiomap>

Bug reports should include the package and R versions, operating system, input
class, CRS, head unit, vertical datum when known, function call, complete warning
or error, synthetic reproducer, and `sessionInfo()`.

Do not post confidential well coordinates, client data, private site
identifiers, or restricted environmental data in a public issue.
