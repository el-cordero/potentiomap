# Manual GitHub repository settings

Public inspection on 2026-07-16 found that the repository is public and the
Issues page is visible, but issue creation is restricted. The repository page
also reports no description, website, or topics. Authenticated GitHub access
was unavailable, so no setting was changed.

Apply these settings in `el-cordero/potentiomap` after maintainer review.

## Issue reporting

1. Open **Settings > General > Features**.
2. Enable **Issues**.
3. Open <https://github.com/el-cordero/potentiomap/issues/new/choose> while
   signed out or in a private window.
4. Confirm that an ordinary public user can choose the bug, feature, or
   documentation forms and that issue creation is not restricted.

## Repository information

Open the repository homepage, choose **About > Edit repository details**, and
set:

- Description: `R tools for preparing groundwater observations, interpolating potentiometric surfaces, and creating contours and hydraulic-gradient arrows.`
- Website: `https://el-cordero.github.io/potentiomap/`

Add these topics:

- `r`
- `groundwater`
- `hydrogeology`
- `geostatistics`
- `spatial-analysis`
- `gis`
- `potentiometric-surface`
- `kriging`

Do not mark these actions complete until the public repository page displays
the description and website and an unauthenticated user can reach the issue
form chooser.
