# Security policy

The current CRAN release and the forthcoming 0.2.x release line receive security
updates. Older versions may be asked to upgrade before a report is investigated.

Please report a suspected security vulnerability privately to
elvin.cordero@seamountgeo.com. Do not open a public issue until the maintainer
has assessed whether disclosure could put users or data at risk. Include the
potentiomap version, R version, operating system, affected function, impact, and
a synthetic reproducer when possible.

Never send confidential well coordinates, credentials, client data, private
site identifiers, or restricted environmental data. A security policy does not
replace an organization's own review of groundwater data handling and GIS
export controls.
