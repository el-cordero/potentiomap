# Synthetic surface shapes and hydrogeologic covariates

A small projected grid containing land-surface elevation, distance from
a valley axis, and known planar, bowl, saddle, and elongated-valley head
surfaces. These are mathematical fixtures, not real aquifers.

## Usage

``` r
synthetic_covariates
```

## Format

A 224-row grid in EPSG:26916; elevations and heads are metres and
distances are metres.

## Source

Generated by `data-raw/generate-expansion-data.R`.
