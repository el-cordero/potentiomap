# Synthetic independent validation points

Fourteen fixed-seed points sampled independently from a known planar
head field with small Gaussian measurement perturbations.

## Usage

``` r
synthetic_validation_points
```

## Format

A 14-row projected point table in EPSG:26916 with head in metres.

## Source

Generated by `data-raw/generate-expansion-data.R` with seed 20260717.
