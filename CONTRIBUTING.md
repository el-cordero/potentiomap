# Contributing to potentiomap

Focused corrections, documentation improvements, tests, and scientifically
justified features are welcome. Please open an issue before a large change.

Use a small branch and keep changes limited to one purpose. Add tests based on
synthetic data, regenerate roxygen documentation when interfaces change, run the
test suite, and describe scientific assumptions and compatibility effects in the
pull request.

Do not submit confidential well coordinates, client data, private site
identifiers, restricted environmental data, or manuscript analysis material.
Examples and tests must run without internet access and write only to temporary
directories.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
For usage help and reproducible problems, see [SUPPORT.md](SUPPORT.md).
